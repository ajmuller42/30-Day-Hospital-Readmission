# 30-Day-Hospital-Readmission
Department of Health and Human Services Machine Learning Project

Question: which diabetic inpatient encounters will be readmitted within 30 days, so a nurse can call the riskiest 20% after discharge? 

Data: Diabetes 130-US Hospitals 1999–2008 (UCI, CC BY 4.0): about 101,800 encounters, about 50 features (demographics, diagnoses, labs, medications). Readmitted < 30 days is about 11%.
